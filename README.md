# Creador de hábitos

La aplicación ayuda a sus usuarios a crear y mantener hábitos, a través de una página web que les permite organizar y realizar un seguimiento de sus tareas. También fomenta la constancia y la satisfacción personal del usuario mediante un sistema de puntos creciente según la racha de cumplimiento.

## Tecnologías

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Instalación

1. Clonar el repositorio.
2. Copiar config/database.example.php como config/database.php, configurando los datos de conexión a MySQL.
3. Crear la base de datos.
4. Importar `database/tablas_bbdd.sql`.
5. Iniciar el servidor.

## Funcionalidades

- Registro e inicio de sesión
- Creación de tareas que deben cumplirse determinados días de la semana
- Seguimiento de tareas mediante un registro de tareas diario
- Sistema de puntos
- Rachas de cumplimiento de las tareas
